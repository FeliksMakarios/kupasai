Kenapa Linear Gagal?

Data donat butuh batas keputusan berbentuk lingkaran, sementara model linear hanya bisa membuat satu garis lurus. Hasilnya: model linear cuma tebak-tebakan (52% — nyaris sama dengan koin lempar).

Menumpuk layer linear tanpa aktivasi tidak menolong — secara aljabar, dua transformasi afin berurutan tetap kolaps jadi satu transformasi afin (Modul 6.3.2).

Menambahkan ReLU di hidden layer membuat jaringan bisa membentuk batas keputusan poligonal yang melingkar — akurasi naik ke 100%.

Delta di layer_2 (output) disebarkan mundur ke empat node di layer_1 lewat bobot weights_1_2 = {0.0, 0.5, 1.0, −1.0}.

Error Mengalir Mundur

Setiap node di layer_1 menerima bagian dari error output, sebanding dengan bobot koneksinya: δ(1)i = δ(2) × wi.

Node dengan bobot 0 tidak menerima error sama sekali (delta=0), sedangkan bobot negatif membalik arah delta — inilah mekanisme di balik backpropagation.

Geser slider untuk melihat bagaimana perubahan error output ikut mengubah keempat delta hidden layer secara proporsional.

ReLU: max(0, x) Sigmoid: 1/(1+e−x) Tanh: tanh(x)

Tiga Aktivasi Umum

ReLU mematikan nilai negatif (jadi 0) dan meloloskan nilai positif apa adanya — murah dihitung, jarang mengalami vanishing gradient pada sisi positif.

Sigmoid memetakan ke rentang (0,1) — cocok untuk output probabilitas, tapi gradiennya mengecil drastis di ujung kurva (vanishing gradient).

Tanh memetakan ke (−1,1), terpusat di 0 — sering lebih stabil dari sigmoid untuk hidden layer, walau tetap punya masalah vanishing gradient di ujungnya.
