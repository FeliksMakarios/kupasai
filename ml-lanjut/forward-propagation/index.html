Forward Propagation

Bagaimana neural network membuat prediksi? Jelajahi lima skenario — dari satu input satu bobot, hingga jaringan dua lapis — dan lihat perhitungan dot product-nya langkah demi langkah.

Tujuan Modul 2: Mahasiswa memahami mekanisme forward propagation dalam neural network untuk prediksi, serta mampu membuat prediksi dengan multiple inputs/outputs menggunakan operasi vektor dan matriks (w_sum, ele_mul, vect_mat_mul).

Dari Node ke Prediksi

Setiap prediksi dihitung dengan operasi yang sama: kalikan setiap input dengan bobotnya, lalu jumlahkan (w_sum). Garis biru = bobot positif, garis merah = bobot negatif. Ketebalan garis menunjukkan besarnya bobot.

Pada Banyak Output, satu input dikalikan beberapa bobot berbeda (ele_mul) untuk menghasilkan beberapa prediksi sekaligus.

Pada Banyak Input & Output, setiap output adalah dot product input dengan satu baris matriks bobot (vect_mat_mul) — inilah operasi inti di balik setiap layer neural network.

Jaringan 2 Lapis menumpuk dua operasi ini: input → hidden layer (ih_wgt) → output (hp_wgt). Nilai hidden layer tidak ada sampai dihitung lewat forward pass.

Dot Product dengan NumPy: Kapan Berhasil, Kapan Gagal

Kenapa Ini Penting?

        muncul saat pertama kali membangun forward propagation manual.
      

      

        Solusinya: selalu cek .shape setiap array sebelum
