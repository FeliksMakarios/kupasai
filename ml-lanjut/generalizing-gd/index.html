Generalizing Gradient Descent

Memperluas gradient descent ke banyak bobot sekaligus: bagaimana jika satu bobot dibekukan? Bagaimana jika ada banyak output? Bagaimana jika keduanya terjadi bersamaan?

Tujuan Modul 4: Mahasiswa mampu menerapkan gradient descent pada pembelajaran dengan multiple inputs dan multiple outputs, serta menganalisis efek freezing weights terhadap hasil prediksi.

Membekukan Satu Bobot

Input: toes=8.5, wlrec=0.65, nfans=1.2, target menang=1. Setiap bobot punya weight_delta sendiri (delta × input_ke-i).

Saat weight[0] (bobot toes) dibekukan, weight_delta[0] dipaksa 0 sehingga bobot itu tidak pernah berubah — tapi jaringan tetap belajar lewat dua bobot lainnya karena error sama-sama menurun.

Ini menunjukkan neuron lain bisa "mengambil alih" pekerjaan belajar walau satu koneksi dibekukan.

Input: wlrec=0.65. Bobot awal: [0.3, 0.2, 0.9] → tiga output sekaligus (hurt, win, sad). alpha=0.1.

Satu Input, Tiga Prediksi

Ketiga output memakai input yang sama tapi bobot berbeda. Prediksi win paling jauh dari target (delta=−0.87), sehingga bobotnya berubah paling besar (0.2→0.257).

weight_delta[j] = input × delta[j] — setiap output diperbarui independen, tapi semua berbagi input yang sama.

Input: [toes=8.5, wlrec=0.65, nfans=1.2]. Target: [hurt=0.1, win=1, sad=0.1]. alpha=0.01.

Kasus Paling Umum

Setiap sel matriks bobot menghubungkan satu input ke satu output. weight_delta[i][j] = input[i] × delta[j] adalah outer product antara vektor input dan vektor delta.

Merah = bobot negatif, hijau = bobot positif. Perhatikan baris toes berubah paling drastis karena nilainya (8.5) jauh lebih besar dari wlrec dan nfans — ilustrasi kenapa normalisasi input penting.
