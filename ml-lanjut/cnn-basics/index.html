CNN Dasar: Konvolusi & Pooling

Bagaimana filter kecil bisa mendeteksi tepi pada gambar? Geser kernel 3×3 di atas gambar dan lihat feature map terbentuk langkah demi langkah, lalu telusuri arsitektur CNN lengkap.

Tujuan Modul 10: Mahasiswa mampu menjelaskan konsep dasar CNN dan bagaimana CNN mengklasifikasikan gambar melalui mekanisme konvolusi, pooling, dan deteksi fitur, serta mengimplementasikan model CNN untuk tugas klasifikasi gambar.

Gambar 6×6 dengan tepi vertikal (kiri terang, kanan gelap) dan kernel deteksi tepi vertikal klasik [[1,0,-1],[1,0,-1],[1,0,-1]]. Geser posisi kernel untuk melihat perhitungan konvolusinya.

Filter Mendeteksi Tepi

Kernel ini menghitung selisih kiri−kanan di setiap posisi. Saat berada tepat di atas tepi vertikal gambar (kolom 1–2), hasilnya besar (30) — menandakan "ada tepi di sini". Di area seragam (semua terang atau semua gelap), hasilnya 0.

Max pooling lalu mengecilkan feature map 4×4 menjadi 2×2 dengan mengambil nilai maksimum tiap blok 2×2 — mempertahankan sinyal tepi yang kuat sambil mengurangi ukuran data.

Tiga Jenis Layer

Conv2D mengekstrak fitur visual (tepi, sudut, tekstur) memakai banyak kernel/filter sekaligus — layer pertama 32 filter, layer kedua 64 filter (semakin dalam, semakin kompleks fiturnya).

MaxPooling2D mengecilkan ukuran feature map tanpa kehilangan sinyal penting, sekaligus membuat model lebih tahan terhadap pergeseran kecil posisi objek.

Dense (fully connected) di akhir menggabungkan semua fitur yang diekstrak untuk membuat keputusan klasifikasi akhir lewat softmax.
