Text Classification Pipeline

Dari teks mentah menjadi prediksi kelas. Pipeline lengkap text classification, dari preprocessing hingga deep learning dengan BERT.

Sub-CPMK 3.1: Mahasiswa mampu mengimplementasikan model NLP menggunakan pustaka modern untuk klasifikasi teks.
Langkah 1 / 5

Pipeline Klasifikasi Teks

Klasifikasi teks adalah tugas menentukan kategori (label) untuk sebuah dokumen. Contoh: analisis sentimen (positif/negatif), deteksi spam, kategorisasi berita.

Pipeline dimulai dari preprocessing (pembersihan teks), lalu vektorisasi (konversi ke angka), dan akhirnya klasifikasi oleh model machine learning.

Setiap tahap memengaruhi kualitas akhir. Preprocessing yang buruk merusak vektorisasi. Vektorisasi yang buruk merusak klasifikasi. Inilah mengapa setiap langkah penting untuk dipahami.

Di dunia nyata, pipeline ini dibungkus dalam library seperti scikit-learn (pipeline klasik) atau Hugging Face Transformers (pipeline deep learning).

Decision Boundary

Setelah teks diubah menjadi vektor (2 dimensi di sini untuk visualisasi), classifier mempelajari garis pemisah antar kelas. Garis ini disebut decision boundary.

Logistic Regression: hanya bisa garis lurus. Sederhana tapi sering cukup baik untuk teks karena vektor teks cenderung terpisah secara linear.

Naive Bayes: probabilistik, mengasumsikan fitur independen. Boundary cenderung linear, posisinya sedikit berbeda dari logistic regression.

SVM (RBF): dengan kernel non-linear, SVM bisa membuat boundary melengkung yang mengikuti data lebih dekat, tapi berisiko overfitting.

Bandingkan ketiga classifier dengan mengklik tombol di atas. Perhatikan bagaimana boundary berubah bentuk.

Langkah 1 / 4

Fine-tuning BERT

Alih-alih melatih model dari nol, pendekatan modern menggunakan transfer learning: ambil model yang sudah dilatih pada korpus besar, lalu sesuaikan (fine-tune) untuk tugas spesifik.

Model pralatih menyediakan representasi awal yang kemudian disesuaikan pada data berlabel. Jumlah epoch dan akurasi bergantung pada dataset, pembagian data, serta konfigurasi. Matriks kebingungan pada halaman ini adalah contoh ilustratif, bukan laporan pelatihan IndoBERT.

Ini jauh lebih efisien daripada melatih dari awal, dan inilah pendekatan standar dalam NLP modern setelah munculnya Transformer.

Confusion matrix ilustratif di langkah terakhir menunjukkan distribusi prediksi: diagonal = benar, off-diagonal = salah.
