Question Answering

Menggabungkan pemahaman (memahami pertanyaan & konteks) dengan ekstraksi atau generasi jawaban. Dari span classification ekstraktif hingga Retrieval-Augmented Generation (RAG).

Tujuan Modul 11: Mahasiswa memahami arsitektur retriever-reader, tokenisasi untuk QA, span classification, dan pendekatan generative QA dengan RAG.

Span Classification (Modul 11.2)

Format input: [CLS] pertanyaan [SEP] konteks [SEP] — token abu-abu adalah pertanyaan (tidak bisa dipilih), token lain adalah konteks.

Start logit (biru) & end logit (hijau) tiap token — oranye = argmax:

Klik token konteks untuk set:

Contoh Nyata: ExtractedAnswer (Haystack)

Membandingkan Model pada SQuAD 2.0

Bagaimana Model Menemukan Jawaban

Model tidak memilih satu label, melainkan memprediksi dua posisi: token awal dan token akhir jawaban. Sebuah linear layer di atas hidden state menghitung skor (logit) untuk setiap token menjadi awal atau akhir span.

Contoh nyata dari Modul 11: pertanyaan "How much music can this hold?" pada konteks tentang MP3 — model cenderung memberi skor tertinggi pada "1"/"6000" untuk start dan "MB/minute,"/"hours" untuk end, sehingga jawaban terekstrak "6000 hours".

Pilih awal dan akhir hanya pada konteks dengan awal ≤ akhir. Decoder span yang lebih lengkap memaksimalkan skor pasangan di bawah batas panjang jawaban. Dua argmax independen dapat menghasilkan span tidak sah. Skor pada panel ini dirancang sebagai ilustrasi.

Sliding Window untuk Konteks Panjang

Pertanyaan: "" · max_length=, stride=

Bagian yang di-highlight adalah kalimat yang tumpang tindih (overlap) antar window — contoh nyata dari ulasan headphone Koss di Modul 11.2.

Contoh Nyata: Generative QA dengan RAG

Q:

Pertanyaan lain yang dicoba pada dataset Seven Wonders:

    Dua Cara Mengatasi Keterbatasan

    Sliding window mengatasi konteks yang melebihi batas token model: teks dipecah jadi beberapa window yang saling tumpang tindih (diatur oleh stride) agar jawaban yang berada di perbatasan window tidak hilang.

    RAG (Retrieval-Augmented Generation) mengatasi keterbatasan extractive QA yang hanya bisa mengutip teks persis: retriever mengambil dokumen relevan, lalu LLM men-sintesis jawaban baru berdasarkan konteks tersebut — bukan sekadar memotong span.

    Jawaban RAG di atas asli dari pipeline Haystack + Qwen2.5-1.5B-Instruct pada dataset Wikipedia "Seven Wonders of the Ancient World".

    Panduan Belajar Mandiri

    Prasyarat: Tokenisasi dan Transformer. Durasi: sekitar 30 menit.

    Asal data dan batas contoh

    Skor span manual, contoh jawaban tersimpan, serta ilustrasi sliding window dan RAG.

    Span harus berada pada konteks, awal≤akhir, dan memenuhi batas panjang. Argmax independen tidak menjamin span sah. RAG tidak menjamin jawaban benar.

    1. Prediksi sebelum mencoba: Apa yang terjadi bila start tertinggi berada setelah end tertinggi?
    2. Eksplorasi: Pilih mode Token Awal atau Token Akhir, lalu klik token konteks untuk membentuk span jawaban.
    3. Perhitungan: Jumlahkan skor start dan end untuk span pilihan Anda, lalu periksa apakah span itu sah (awal ≤ akhir dan di dalam konteks).
    4. Refleksi dan transfer: Rancang kasus konteks tidak memiliki jawaban dan bukti yang dibutuhkan.
