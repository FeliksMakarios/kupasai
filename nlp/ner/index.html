Named Entity Recognition

Naik satu tingkat dari klasifikasi teks: memberi label pada setiap token, bukan satu label untuk seluruh kalimat. Multibahasa dengan XLM-RoBERTa dan skema tag IOB2.

Tujuan Modul 9: Mahasiswa memahami teknik NER lintas bahasa, skema IOB2, penyelarasan label pada subword, dan evaluasi level-entitas dengan seqeval.

Klik Token untuk Melihat Tag IOB2-nya

Penyelarasan Subword → Label (Modul 9.6)

Contoh nyata dari notebook: kata Einwohnern dipecah SentencePiece menjadi dua subword, ▁Einwohner dan n. Hanya subword pertama (kotak biru) yang dapat label asli; sisanya ditandai IGN (diabaikan, ID=−100 saat training).

Format IOB2

Prefix B- menandai awal (Beginning) sebuah entitas, I- menandai lanjutan (Inside) entitas yang sama, dan O berarti token tidak termasuk entitas apapun (Outside).

Tanpa prefix B-/I-, dua entitas bertipe sama yang bersebelahan (misalnya "Jeff Dean Tim Cook") tidak bisa dibedakan sebagai satu atau dua nama.

Karena tokenizer subword (SentencePiece) bisa memecah satu kata menjadi beberapa token, strategi penyelarasan dalam contoh ini memakai: hanya subword pertama yang diberi label sebenarnya, sisanya di-mask agar tidak ikut dihitung dalam loss.

Kalkulator seqeval (persis contoh Modul 9.7)

Distribusi Bahasa dalam Korpus PAN-X (Swiss)

Evaluasi Level-Entitas, Bukan Level-Token

Sebuah entitas hanya dianggap benar jika tipe dan rentang entitas hasil parsing sama dengan acuan. Parser permisif dapat menerima I- di awal sebagai entitas baru, sehingga perbedaan tag token belum tentu mengubah entity F1. Mode strict IOB2 menolak awal itu.

Klik tag prediksi manapun di atas untuk mengubahnya, dan lihat precision/recall/F1 dihitung ulang secara langsung. Cobalah geser batas awal entitas MISC satu posisi agar sama persis dengan label sebenarnya — F1 akan naik ke 1,0.

Contoh ini memakai - label NER. Skor eksperimen model lintas bahasa tidak ditampilkan karena checkpoint, versi data, dan hasil evaluasinya belum dapat diverifikasi. Evaluasi di atas dihitung langsung dari dua urutan tag contoh.

Panduan Belajar Mandiri

Prasyarat: Tokenisasi dan klasifikasi. Durasi: sekitar 30 menit.

Asal data dan batas contoh

Contoh IOB2 dan evaluator JavaScript ilustratif. Angka model diwarisi dari materi sumber, bukan eksperimen baru.

Pelabelan hanya subkata pertama adalah pilihan pelatihan. Evaluator panel memakai aturan permisif seperti seqeval default, bukan strict IOB2. Entitas cocok bila tipe dan rentang sama.

  1. Prediksi sebelum mencoba: Apa dampak B-PER berubah menjadi I-PER pada awal urutan?
  2. Eksplorasi: Klik token untuk melihat tag IOB2, lalu ubah tag prediksi pada tab Evaluasi Level-Entitas.
  3. Perhitungan: Hitung precision, recall, dan F1 tingkat entitas setelah satu tag diubah, lalu bandingkan dengan token accuracy.
  4. Refleksi dan transfer: Bandingkan token accuracy dengan entity F1.
