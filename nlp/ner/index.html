Named Entity Recognition

Naik satu tingkat dari klasifikasi teks: memberi label pada setiap token, bukan satu label untuk seluruh kalimat. Multibahasa dengan XLM-RoBERTa dan skema tag IOB2.

Tujuan Modul 9: Mahasiswa memahami teknik NER lintas bahasa, skema IOB2, penyelarasan label pada subword, dan evaluasi level-entitas dengan seqeval.

Klik Token untuk Melihat Tag IOB2-nya

Penyelarasan Subword → Label (Modul 9.6)

Contoh nyata dari notebook: kata Einwohnern dipecah SentencePiece menjadi dua subword, ▁Einwohner dan n. Hanya subword pertama (kotak biru) yang dapat label asli; sisanya ditandai IGN (diabaikan, ID=−100 saat training).

Format IOB2

Prefix B- menandai awal (Beginning) sebuah entitas, I- menandai lanjutan (Inside) entitas yang sama, dan O berarti token tidak termasuk entitas apapun (Outside).

Tanpa prefix B-/I-, dua entitas bertipe sama yang bersebelahan (misalnya "Jeff Dean Tim Cook") tidak bisa dibedakan sebagai satu atau dua nama.

Karena tokenizer subword (SentencePiece) bisa memecah satu kata menjadi beberapa token, PAN-X mengikuti konvensi BERT: hanya subword pertama yang diberi label sebenarnya, sisanya di-mask agar tidak ikut dihitung dalam loss.

Kalkulator seqeval (persis contoh Modul 9.7)

Distribusi Bahasa dalam Korpus PAN-X (Swiss)

Evaluasi Level-Entitas, Bukan Level-Token

Sebuah entitas hanya dianggap benar jika seluruh token penyusunnya cocok persis dengan label sebenarnya — satu token salah, seluruh entitas dianggap salah.

Klik tag prediksi manapun di atas untuk mengubahnya, dan lihat precision/recall/F1 dihitung ulang secara langsung. Cobalah geser batas awal entitas MISC satu posisi agar sama persis dengan label sebenarnya — F1 akan naik ke 1,0.

Model XLM-R yang di-fine-tune pada data German mencapai F1 ≈ - pada test set German (- label NER total). Saat ditransfer zero-shot ke French/Italian/English, performa menurun. Model juga paling sering tertukar antara B-ORG dan I-ORG.
