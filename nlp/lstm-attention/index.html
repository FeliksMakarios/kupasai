LSTM, GRU & Classical Attention

Dari "menyimpan" ke "memilih": bagaimana gerbang memori LSTM/GRU mengontrol aliran informasi, dan bagaimana attention klasik membiarkan decoder "melirik kembali" ke seluruh input encoder.

Tujuan Modul 4: Mahasiswa memahami intuisi desain LSTM sebagai solusi atas vanishing gradient, peran memory cell dan gating mechanism, serta ide dasar classical (encoder-decoder) attention.

Encoder Punya 5 Hidden State

Kalimat "saya suka belajar deep learning" di-encode menjadi 5 hidden state 2D (titik biru). Decoder membawa query (garis putus-putus dari origin) yang menentukan bagian mana yang paling relevan.

scorei = hi · query, lalu dinormalisasi dengan softmax menjadi αi. Context vector (lingkaran hijau) adalah rata-rata berbobot Σαihi — selalu jatuh di antara titik-titik yang paling diperhatikan.

Coba geser query ke arah "suka" (qx=1, qy=0) lalu ke arah "belajar/deep/learning" (qx=0, qy=1) — perhatikan context vector "bergerak" mengikuti fokus perhatian.
