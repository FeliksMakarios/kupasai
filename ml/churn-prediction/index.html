Studi Kasus: Churn Prediction

Memprediksi pelanggan mana yang berisiko berhenti berlangganan, agar tim pemasaran bisa menyasar promosi retensi secara tepat.

Modul 9: Mahasiswa mampu membangun dan membandingkan model Logistic Regression dan Random Forest untuk prediksi churn, lalu menerjemahkan hasilnya menjadi insight bisnis.
Aktif Churn

Logistic Regression vs Random Forest

Parameter terbaik hasil GridSearchCV (5-fold):

Feature Importance (Random Forest)

Dataset Nyata: ABC Telekom

10.000 pelanggan kartu prabayar internet nirkabel, dengan fitur perilaku penggunaan (reload, internet, video, musik, chat, media sosial) serta tenure dan days_active.

Sebelum training, tiga fitur yang berkorelasi tinggi dengan pasangannya (reload_2, socmed_2, games) dibuang lewat Pearson correlation — hanya salah satu dari tiap pasangan yang disimpan.

Random Forest jauh mengungguli Logistic Regression di semua metrik, terutama recall — menandakan model non-linear lebih mampu menangkap pola perilaku churn yang kompleks. tenure, reload, dan days_active adalah tiga fitur paling menentukan, sesuai hipotesis awal modul.

Dipilih dari - pelanggan di test set

Bandingkan Prediksi

Pilih pelanggan dari test set dan lihat bagaimana kedua model memprediksi status churn-nya, dibandingkan dengan label sebenarnya.

Perhatikan pelanggan dengan tenure pendek dan days_active rendah — ini biasanya yang paling sering diprediksi churn oleh Random Forest.
