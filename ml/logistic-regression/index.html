Logistic Regression

Bukan memprediksi angka, tapi probabilitas: apakah sebuah data termasuk kelas A atau kelas B?

Sub-CPMK 2.2: Mahasiswa dapat mengimplementasikan regresi logistik dengan Scikit-learn dan mengevaluasi model menggunakan metrik seperti akurasi.
Akurasi (test set)-
Confusion Matrix (TN/FP/FN/TP)-
Setosa Versicolor Lingkaran bergaris tebal = data test set

Garis putus-putus mengikuti ambang keputusan. Isi titik = kelas aktual; garis tepi = kelas prediksi; titik data uji lebih besar. Latar menunjukkan probabilitas yang tetap saat ambang berubah.

Data Nyata: Iris

100 sampel bunga Iris (kelas setosa vs versicolor), memakai dua fitur pertama: panjang & lebar sepal.

Warna latar adalah probabilitas hasil model.predict_proba() sungguhan di setiap titik grid — oranye berarti model yakin setosa, biru berarti yakin versicolor. Batas di tengah (warna netral) adalah decision boundary.

Kedua kelas pada dataset ini terpisah sangat rapi secara linear, sehingga model mencapai akurasi 100% pada test set.

Dari Angka ke Probabilitas

Logistic Regression menghitung kombinasi linear z = b + w1×x1 + w2×x2, lalu memasukkannya ke fungsi sigmoid: 1 / (1 + e-z) supaya hasilnya selalu di antara 0 dan 1.

Titik biru pada kurva bergerak sesuai slider — geser dan perhatikan bagaimana probabilitas berubah drastis di sekitar z = 0 (P = 0.5), tapi melandai di ujung-ujungnya.

w dan b yang dipakai di sini adalah koefisien asli hasil training pada tab sebelumnya, bukan angka rekaan.
