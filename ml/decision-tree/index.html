Decision Tree

Membagi data lewat serangkaian pertanyaan ya/tidak, sampai setiap cabang berisi kelas yang (hampir) murni.

Sub-CPMK 2.2: Mahasiswa dapat mengimplementasikan decision tree dengan Scikit-learn dan mengevaluasi model menggunakan metrik seperti F1-score.

Dataset Kendaraan (15 baris)

Contoh persis dari Modul 5.1: mengklasifikasi sedan vs minibus berdasarkan mesin, jumlah bangku, dan penggerak.

Entropy mengukur ketidakpastian — 0 berarti murni satu kelas, mendekati 1 berarti campuran. Information Gain adalah seberapa besar entropy turun setelah split.

Fitur terbaik untuk root node: - — IG-nya paling besar dari ketiga kandidat.

Akurasi test set: - · Dataset: - baris

Pohon Sungguhan

Ini bukan diagram rekaan — struktur, ambang batas (threshold), dan jumlah sampel di tiap node diambil langsung dari DecisionTreeClassifier(criterion='entropy', max_depth=3) yang dilatih pada 40 baris decisiontree_ch6.csv.

Setiap kotak internal adalah pertanyaan; ikuti cabang ya atau tidak sampai mencapai daun (kotak berwarna) berisi prediksi akhir.

Perhatikan node root: bangku ≤ 4.5? — sama seperti temuan di tab sebelumnya bahwa fitur bangku punya Information Gain tertinggi.
